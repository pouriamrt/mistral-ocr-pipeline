Comparison Methodology

  • Matching: Papers matched by title similarity (fuzzy, threshold 0.6) with fallback to year + journal combination.
  • Semantic comparison: Each field is compared at the concept level, not keyword level. Both human and LLM values are mapped to canonical clinical/scientific concepts before comparison.
  • Scoring: Exact = 1.0, Close/Compatible = 0.7-0.85, Partial = 0.25-0.75 (Jaccard-weighted), Extra = 0.25, Missing/Disagree = 0.0. Both Empty excluded from scoring.
  • Study design: Uses compatibility groups (e.g., "Cohort Study" and "Non-Randomized Observational Study" are compatible at 0.7).
  • Clinical outcomes: Human's separate Yes/No flags (Bleeding, Stroke/TIA, DVT/PE) are unified into a concept set and compared against LLM's list extraction. "Thromboembolism" maps to both Stroke/TIA and DVT/PE.
  • Comparator assays & coagulation tests: Both sides mapped to canonical assay concepts (PT, aPTT, TGA, anti-Xa, VET, etc.) regardless of naming differences.
